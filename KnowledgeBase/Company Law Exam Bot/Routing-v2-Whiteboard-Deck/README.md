# Routing v2 Consolidated Whiteboard Presentation

This folder contains one consolidated 22-slide photographed-whiteboard presentation for
explaining Routing v2 to a non-technical audience.

## Contents

- `slide-01.png` to `slide-22.png` - final 16:9 presentation slides
- `presentation-guide.md` - recommended short/full presentation order and talk track
- `detailed-notes.md` - detailed explanation of allowlist, actual_open, six locks, XOR,
  document chains, validation and hash controls
- `render-contract.md` - exact visible text, slide purpose and diagram contract
- `prompt-manifest.md` - final prompt summary, factual basis and repair record

## Presentation chapters

1. Slides 1–6 - Routing v2 overview and file relationships
2. Slides 7–10 - ordinary bot versus Routing v2
3. Slides 11–17 - allowlist, actual_open, six locks and XOR
4. Slides 18–22 - hash, secret file additions and the full protection model

All raster slides were generated through built-in ImageGen using the same physical
whiteboard and marker-style anchors. Every final slide is 1672×941 pixels.

Start with `presentation-guide.md` if presenting to friends. Use `detailed-notes.md` for
questions or a deeper technical explanation.
