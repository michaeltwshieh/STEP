# Non-Core Exam Bot Files

This folder holds generated deliverables, working files, render previews, and local
system metadata that were separated from the shareable exam-bot package.

Nothing here was deleted. The original directory structure is preserved under the
name of the source bot so files can be restored if needed.

Generated binaries and render previews under `output/`, `tmp/pdfs/`, and
`tmp/docx-render-*` remain local-only because the repository intentionally ignores
those paths. Trackable working files such as draft answers, marking notes, RoutePlans,
and build scripts are preserved here in Git.

## Company-Law-Exam-Bot-Routing-v2-Test

- `output/`: generated whiteboard slides, PDFs, DOCX output, and the ZIP package.
- `tmp/`: draft answers, marking notes, RoutePlans, render previews, and build scripts.
- `system-metadata/`: `.DS_Store` files moved out of the bot tree.
