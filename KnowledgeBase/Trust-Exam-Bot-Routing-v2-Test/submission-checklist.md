# Before you submit — upload checklist

When the user is preparing to upload, remind them:

- **No name anywhere** in the answer or the file name (watch browser auto-fill).
- **One file only** — Section B is a single upload (.doc or .pdf).
- **Cover page** with: submission date, Customer Contact Number, course title, number of pages.
- Format for **black-and-white printing**.
- **Mind the deadline** — 10% deduction if up to 30 min late, 15% if 31–60 min, not accepted after 60 min. Don't leave the upload to the last minute.
